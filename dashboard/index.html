How the model is calibrated

The category multiple is the median market-cap/TVL the snapshot's own traded protocols in that category actually carry (categories with fewer than three traded samples fall back to the global median). Growth scales the 7-day TVL change, clamped so one wild week cannot dominate; maturity rewards protocols that have run for years with no token over ones listed last month; breadth adds 4% per extra chain. Every number on this page traces to the snapshot — change the snapshot and the board changes.
