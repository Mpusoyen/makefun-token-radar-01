PRE-TOKEN RADAR

Protocols whose token does not exist yet, ranked by what that token would plausibly be worth — and a concrete plan for farming each one.

The model

Implied value = TVL × category multiple × growth × maturity × breadth. The category multiple is not a guess: it is the median market-cap/TVL the snapshot's own traded protocols in that category actually carry. Growth scales the 7-day TVL change (clamped, so one wild week cannot dominate), maturity rewards protocols that have run for years with no token over ones listed last month, and breadth adds 4% per extra chain. Every number on this page can be traced to the snapshot; change the snapshot and the board changes.
