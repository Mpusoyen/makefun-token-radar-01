Pre-Token Radar: ranks 320 pre-token protocols from the sealed DefiLlama snapshot by an implied value calibrated from the snapshot's own traded protocols (median mcap/TVL per category, adjusted for 7-day growth, maturity and chain breadth), each with a concrete farm plan, on a sortable, filterable dashboard with per-protocol detail views.

## Run it

```sh
node main.ts --input <snapshot.json> writes board.json, data.js, dashboard/ and dossier.json to the output dir; open the dashboard index.html to browse the board.
```
